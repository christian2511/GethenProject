# The Ekumen Report

A static website about Gethen from *The Left Hand of Darkness*.

## Publish with GitHub Pages

1. Create a GitHub repository and upload **the contents of this folder** (not the folder itself).
2. Open the repository **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose **main** and **/(root)**, then Save.
5. Visit the GitHub Pages link displayed in Settings → Pages after deployment.

The homepage is `index.html`. CSS, JS, and images use relative paths so the site works on project GitHub Pages URLs.

If updates look unchanged, force refresh (Ctrl+Shift+R) or wait for GitHub Pages deployment to complete.
